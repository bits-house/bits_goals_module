
# Prompts

This folder contains ready-to-copy prompts used in this repo.

## How to use

1. Open the prompt file you want.
2. Copy/paste it into your AI chat (Copilot Agent with VS Code preferred).
3. Give context (with Copilot Agent: just attach the related files).
4. Run the prompt and iterate as needed.
5. After running the prompt and reviewing the output, consider improving it using the "Improve Prompt" prompt in its folder. It helps refine prompts with what worked well and what didn't, making them more effective and faster for future use, accumulating knowledge from this repo over time.

## Notes

- Prompts are intentionally verbose internally so you can run them “as-is”.
